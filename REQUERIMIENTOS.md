# Requerimientos de la landing page
## Objetivo del sitio

Crear una landing page para captar emprendedores interesados en obtener recursos, herramientas y orientacion para desarrollar sus negocios.

## Publico objetivo

Personas emprendedoras que desean iniciar, organizar o mejorar un negocio mediante recursos y soluciones digitales.

## Secciones del sitio

- Encabezado con logotipo y menu de navegacion.
- Hero con titulo, descripcion y llamado a la accion.
- Seccion de recursos o beneficios.
- Seccion de testimonios.
- Seccion de planes o servicios.
- Formulario de contacto o registro.
- Pie de pagina.

## Requerimientos funcionales

- El menu debe permitir navegar hacia las diferentes secciones.
- Los botones deben responder correctamente a la interaccion del usuario.
- El formulario debe validar los datos antes de registrarlos.
- Los datos del formulario deben administrarse mediante programacion   orientada a objetos.
- El proyecto debe implementar POO con JavaScript y TypeScript.
- La informacion registrada debe poder representarse en formato JSON.
- El sitio debe mostrar mensajes claros cuando los datos sean incorrectos.
- Las animaciones deben activarse correctamente sin afectar la navegacion.

## Requeremientos no funcionales

- El sitio debe ser responsivo en celular, tableta y computadora.
- Los estilos deben estar organizados con SASS.
- Debe utilizar variables, mixins y anidamiento
- Debe incluir transiciones, transformaciones y animaciones con `@keyframes`.
- La interfaz debe ser amigable, ordenada e intuitiva.
- Los colores, botones, textos y espacios deben mantener un diseño consiente.
- El sitio no debe presentar errores en la consola del navegador.
- El Proyecto debe utilizar Git y GitHub para el control de versiones.
- Los cambios deben registrarse mediante ramas y commits descriptivos.

## Tecnologias utilizadas

- HTML5 para la estructura semantica.
- SASS y CSS3 para los estilos y la responsividad.
- JavaScript para la interactividad y la POO.
- TypeScript para desarrollar clases y logica con tipado.
- Vite para ejecutar y compilar el proyecto.
- Git y GitHub para administrar las versiones.

## Criterios de aceptacion

- Todas las secciones cargan correctarmente.
- El menu permite navegar por el sitio.
- El formulario valida y procesa los datos.
- La POO con JavaScript y TypeScript funciona correctamente.
- El sitio se adapta a distintos tamaños de pantalla.
- Las animaciones funcionan con moderacion.
- No aparecen errores en la consola.
- El proyecto se encuentra actualizado en GitHub.
